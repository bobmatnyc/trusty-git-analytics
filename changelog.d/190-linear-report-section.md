Added
- `tga report` and `tga analyze` append the Linear delivery section (the block `tga linear stats` prints) to `report.md` when the new `linear.stats.report: true` is set and the database holds synced Linear issues. The figures are measured as of the report's `Generated` time with the `linear.stats` bounds. The section is left out under `--author`, when Markdown is not among the formats, and when no Linear issue is synced; with the switch off (the default) `report.md` is unchanged. A figure that cannot be computed fails the report with an error starting `Linear delivery section:`, and no report file is written. The report reads the Linear tables and never writes them (#190).
- `core::config::LinearStatsConfig` gains `report` (`#[non_exhaustive]`, default `false`) (#190).

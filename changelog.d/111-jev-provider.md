Added
- `llm.source: jev` routes the LLM tier to TypeSafe's Jev decision model (`TYPESAFE_API_KEY` by default), pinned to `jev-1.13.0`. Each commit is one `choice` question over the configured categories plus `NO_MATCH` / `INSUFFICIENT_INFORMATION`, both recorded as abstentions; abstentions, out-of-set codes and failures never replace the rule verdict, and usage is recorded in `llm_usage` with provider `jev` and the model each reply named. A reply from any other model is recorded as `failed` (#111).
- Jev requests carry only pseudonymized text: e-mails, people (git and Phabricator trailers in any case and spacing, mentions, roster names, every author and alias in the database), ticket keys in any case or brackets, record ids, URLs, hosts, IPv4/IPv6 addresses, file paths, configured repository names, `llm.jev.sensitive_terms` and `llm.jev.id_patterns` become `EMAIL_n`, `PERSON_n`, `TICKET_n`, `ID_n`, `URL_n`, `HOST_n`, `PATH_n`, `REPO_n` and `TERM_n`. Every slash-joined path or branch name becomes `PATH_n` except a fixed list of prose pairs; bare file names (known extensions, build files, and every basename in `files.path`) become `PATH_n`; two-label names on word suffixes such as `acme.dev` are hosts. Payload dumps write an on-host token map next to each body. Category names and descriptions are operator configuration and are sent verbatim; classification vocabulary, generic logins and bot accounts are never treated as names. A message that cannot be pseudonymized is recorded as `failed` and never sent (#111).
- `llm.jev.budget_usd` caps a Jev run's spend (default $0.25) at $0.042 per million input tokens; output tokens are free. Every attempt sent counts against the cap, a timed-out retry included; calls past the cap are recorded as `skipped` (#111).
- `llm.jev.payload_dump_dir` writes each exact Jev request body to a directory and sends nothing; `llm.jev.name_matcher_bytes` (default 64 MiB) caps the name matcher for very large rosters (#111).
- `LlmOutcome::Skipped` and `LlmUsageTotals::skipped`; `tga classify` prints the skipped count and the command that re-sends the skipped commits (#111).

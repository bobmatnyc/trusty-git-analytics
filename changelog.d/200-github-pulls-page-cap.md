- `tga collect` walks a GitHub repository's pull-request listing past 10,000 PRs. The `/pulls` walk has its own 2,000-page (200,000-PR) cap instead of the shared 100-page cap, so a large repository collects fully instead of stopping silently at 10,000. A listing that still stops early, at the cap or on a rate limit after page 1, is reported as PARTIAL in the collect output; the rows fetched before the stop are kept (#200).

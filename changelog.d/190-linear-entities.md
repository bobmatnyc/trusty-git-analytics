Added
- `tga linear sync --entities` also syncs the Linear workspace's teams, users, labels, projects, project milestones and cycles, archived ones included, into six new tables keyed by Linear's id, each with the GraphQL node in `raw_json` (migration v34, additive). Projects keep state, status, start and target dates, completed/canceled times, lead and team ids; cycles keep team, number, dates and the latest scope and completed counts, and a cycle with zero scope is flagged `is_empty` (#190).
- Each entity set is fetched in full, then its rows and its `linear_entity_sync_state` row commit in one transaction. A failed page writes nothing for that set and does not move its state; the summary line reports per-entity counts (#190).
- Library: `collect::linear::entities` (`EntityKind`, `LinearClient::fetch_entity_nodes`, `entities::store::commit_entity_sync` and `get_entity_sync_state`) and two `CollectError` variants, `LinearEntityApi` and `LinearNestedConnectionTruncated` (#190).

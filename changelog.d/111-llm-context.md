Added
- `llm.context` appends commit facts to the LLM user prompt after the message: any of `paths` (changed file paths, capped by `llm.context_max_paths`, default 30, and `llm.context_max_path_bytes`, default 2048), `pr_title` (the linked pull request's title) and `issue_type` (the linked work item's type). The facts come from the `files`, `pull_requests` and `work_items` tables through the joins `tga eval sample` uses. Every source honours it; for `jev` the block is part of the message text, and with `llm.jev.obfuscate: true` it is pseudonymized too, each path as a whole `PATH_n`. The default, `[]`, sends exactly the previous prompt, and an unknown item is a config load error (#111).

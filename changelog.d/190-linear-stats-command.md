Added
- `tga linear stats` prints Linear delivery metrics from the tables `tga linear sync --entities` wrote, with no network call: population, completions per quarter and the four-quarter trend, lead and cycle time, cycle completion and carry-over, title tags, field use, projects, cancel rate, and contributors and concentration, for the workspace and per team key. Markdown by default, the full JSON with `--json` (`schema_version` 1); `--as-of YYYY-MM-DD` measures at midnight UTC at the start of that date. It opens the database read-only: a missing file, or one with pending migrations, fails with the path named and is never created or migrated (#190).
- The optional `linear.stats` config block sets lower bounds for two of those metrics: `field_use_created_since` and `concentration_completed_since` (`YYYY-MM-DD`). A value that is not a date fails the config load (#190).
- Library: `report::linear_stats` (`compute_linear_stats`, `StatsOptions`, `LinearStats`, `render_markdown`, `LINEAR_STATS_SCHEMA_VERSION`), `core::config::LinearStatsConfig`, `commands::linear::{LinearStatsArgs, render_stats, run_stats, run_stats_at}`, and `core::db::Database::open_read_only_with_remedy` (#190).
- `LinearConfig` gains `stats`; `LinearSubcommand` gains `Stats` (both `#[non_exhaustive]`).

# Publishing to crates.io

This document described the old five-crate `tga-core`/`tga-collect`/
`tga-classify`/`tga-report`/`tga-cli` workspace and its fully-automated
`.github/workflows/cd.yml` pipeline. Neither exists in this repository: `tga`
is a single crate at the repo root, `trusty-audit` lives at
`crates/trusty-audit`, and releases are manual.

See **[docs/PUBLISHING.md](../PUBLISHING.md)** for the current checklist.
